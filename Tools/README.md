# Папка Tools

Сюда кладутся ваши утилиты. **Не все программы входят в репозиторий и релизы: часть не распространяется из-за авторских прав и лицензий.** Скачайте нужные программы с сайтов производителей и положите их сюда сами.

```
Tools\
  x64\ x86\        портативные программы и SFX-пакеты
  Apps\<имя>\      программы, распакованные в папки (SDIO, Rufus, Sysinternals…)
  Install\         установщики для вкладки «установка» (7-Zip, Chrome, VLC, Visual C++…)
  Antivirus\       скрипты запуска сканеров (сами сканеры скачиваются при запуске)
```

После добавления файлов нажмите «Обновить список» на вкладке «утилиты». Названия и группы известных программ берутся из `app/data/catalog.json`, остальным можно задать их в `tools.json` рядом с exe.

*Note in English: not all programs are included in this repository or its releases because of copyright and licensing. Download the tools you need from their vendors and put them here.*
