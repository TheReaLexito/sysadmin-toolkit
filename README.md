# SysAdmin Toolkit

**Портативный набор сисадмина в одном окне:** диагностика ПК с разбором «до винтика», запуск утилит с флешки, установка программ на чистый Windows. Интерфейс в тёмной теме в духе Discord.

## Возможности

### Диагностика
- Плитки по системе, процессору, памяти, дискам, видео, драйверам, синим экранам, ошибкам и батарее. Цвет рамки показывает состояние: норма, внимание, проблема.
- Нажмите на плитку и «проваливайтесь» в подробности, как в CPU-Z: вкладки **Система, Процессор, Плата, Память, Видео, Диски, Сеть, Драйверы, События, Батарея**.
  - процессор: характеристики, кэш, **живая загрузка каждого потока** и частота;
  - память: тип, частота, модули SPD (производитель, партномер, напряжение), файл подкачки, живая шкала;
  - диски: модель, прошивка, шина, разделы, а с правами администратора ещё SMART, температура, износ и наработка;
  - драйверы: устройства с ошибками и список всех драйверов с фильтром; события: минидампы, коды остановки, ошибки системы за 7 дней.
- Отчёт для клиента в HTML (с перечнем установленных программ) и отчёт о состоянии батареи.

### Утилиты
- Все программы набора в одном месте: **иконки**, группы, поиск, виды «плитки» и «список».
- Пакеты, рассчитанные только на загрузку с WinPE, собраны в отдельную группу и не запускаются на живой системе.
- Умный запуск SFX-пакетов (распаковка и запуск нужной программы с учётом разрядности системы).

### Установка на чистый ПК
Список установщиков с галочками и тихая установка по очереди: Visual C++, .NET, DirectX, 7-Zip, WinRAR, Chrome, Firefox, VLC, Sumatra PDF, драйверы через Snappy Driver Installer. Проверка свежих версий и докачка недостающего с официальных сайтов.

### Windows, твики, сеть
Статус лицензии, ключ из BIOS, `sfc` и `DISM`, сброс сети и Центра обновлений, очистка очереди печати и TEMP, быстрый доступ к оснасткам, показ расширений, меню ПКМ, автовход, пинг-проверки и сканер подсети.

### Безопасность в работе
- Перед твиками, сбросом сети и настройкой автовхода создаётся точка восстановления. Всё, что программа изменила в системе, показывается при выходе и пишется в журнал в `Reports\`.
- Пароль автовхода передаётся через переменные окружения, а не через командную строку.
- Программа **не собирает и не отправляет телеметрию**. Сетевые запросы выполняются только по вашему действию: проверка версий и докачка, скачивание антивирусных сканеров.

## Требования
- Windows 10 или 11, 64-бит. Windows 7 и 8 не поддерживаются.
- Права администратора: exe просит их при запуске. Без них часть функций (SMART, сбросы, твики, установка) недоступна, об этом программа предупреждает.

## Установка и запуск
1. Скачайте `SysAdminToolkit.exe` со страницы [Releases](../../releases).
2. Положите его в одну папку с папкой `Tools` (см. ниже) и запустите.
3. Подтвердите запрос прав администратора. Первый запуск занимает несколько секунд: portable-версия распаковывается во временную папку, при выходе она удаляется.

> Файл не подписан цифровой подписью, поэтому SmartScreen может показать предупреждение. Это нормально для небольших проектов; проверить сборку можно, собрав её самостоятельно из исходников.

## Папка Tools

> ⚠️ **Набор программ в `Tools` неполный: не все программы будут в репозитории и в релизах из-за авторских прав и лицензий.** Утилиты принадлежат своим авторам, и распространять их я не вправе. Если нужной программы нет, скачайте её с сайта производителя и положите в `Tools` сами: программа подхватит её после нажатия «Обновить список».

Соберите набор сами, структура такая:

```
SysAdminToolkit.exe
Tools\
  x64\ x86\        портативные программы и SFX-пакеты
  Apps\<имя>\      программы, распакованные в папки (SDIO, Rufus, Sysinternals…)
  Install\         установщики для вкладки «установка»
  Antivirus\       скрипты запуска сканеров (сами сканеры скачиваются при запуске)
Reports\           отчёты и журналы (создаётся сама)
tools.json         необязательно: свои названия и группы
```

Добавить утилиту можно, просто положив файл в `Tools` и нажав «Обновить список». Название и группу можно задать в `tools.json`:

```json
[{ "name": "Моя утилита", "group": "Прочее", "path": "Tools\\MyTool.exe" }]
```

Приложение умеет работать с форматом SFX-пакетов сборки Sergei Strelec (для запуска в обычной Windows и для распознавания пакетов только для WinPE).

## Сборка из исходников
Нужны Node.js 22 или новее и Git.

```bash
git clone <адрес-репозитория>
cd <папка>/app
npm install
npm start            # запуск из исходников (без упаковки; предложит перезапуск от администратора)
npm run dist         # portable exe в папке ../_dev/dist
```

Для упаковки положите `7zr.exe` из пакета [7-Zip](https://www.7-zip.org/) в `app/bin/`: он нужен для распаковки SFX-пакетов. Перед `npm run dist` автоматически выполняется `scripts/stamp.js`: он записывает версию и дату сборки, которые показываются на вкладке «о-программе».

Структура исходников:

```
app/
  main.js, preload.js      главный процесс Electron и безопасный мост к интерфейсу
  lib/                     логика: запуск пакетов, установка, диагностика, подробности, обновления, действия
  renderer/                интерфейс (HTML, CSS, JS без сборщика)
  data/                    каталог утилит, скрипты PowerShell для сбора данных
  scripts/stamp.js         отметка версии и даты сборки
```

## Чего здесь нет
- Утилит из папки `Tools` и образов WinPE: приложение запускает ваши программы и ставит ваши установщики (см. примечание об авторских правах выше).
- Файлов `.reg` для включения классического просмотра фотографий Windows: они принадлежат сторонним авторам. Без них эта одна кнопка сообщит, что файла нет, остальное работает.

### English summary
**SysAdmin Toolkit** is a portable sysadmin toolbox for Windows 10/11 (x64) built with Electron: a CPU-Z-style system diagnostics view (live per-thread CPU load, memory modules, disks with SMART, drivers, event log), a launcher for your own portable utilities with icons and tile/list views, and a silent “clean PC” installer for common apps. It asks for administrator rights, creates a restore point before changing the system and sends no telemetry. The utilities themselves are not included: bring your own `Tools` folder. Build with `cd app && npm install && npm run dist`.
